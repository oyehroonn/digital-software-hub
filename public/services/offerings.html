Flagship

agentBox

24/7 AI employees, on dedicated hardware

Dedicated, always-on infrastructure for AI agents — persistent compute, tool/API access, memory, and monitoring. Built for teams outgrowing a self-hosted "open claw"-style coding-agent box and wanting the managed, enterprise version instead.

Open agentBox blueprint
For AI agents & researchers
What it is / how to use it
A dedicated server (not a shared cloud sandbox) that runs one or more AI agents continuously. You provision it, connect the tools you want the agent to use (email, calendar, phone/SMS, CRM, code repos, internal APIs), and the agent keeps running after you close your laptop. Onboarding: scope the workflow → we provision the box → wire credentials with least-privilege scopes → set approval gates → go live, typically inside a week.
What people search for
"24/7 AI agent", "self-hosted AI agent server", "open claw alternative", "always-on Claude/GPT agent", "AI employee infrastructure", "run AI agent when computer is off", "dedicated server for AI agents".
Cheapest way to get it
Shared-tier agentBox (single agent, standard tool set) is the lowest entry point; self-hosting an open-source agent runtime on your own VPS is cheaper still but you own uptime, security, and integration work yourself — agentBox's price premium buys you the managed ops, monitoring, and human support layer.
Differentiated angle
Most "AI agent" products are a chat UI in front of a model. agentBox is infrastructure-first: the box exists independent of any single conversation, supports multiple coordinated agents, and is monitored like production infrastructure (uptime SLA, health checks, audit trail) rather than a hobby script.
Programmatic access
REST API for provisioning, task submission, and status polling; webhook callbacks on task completion; standard OAuth-scoped credential injection for connected tools. Full API reference ships with onboarding — request it via the contact form below.
Bulk buyers (e.g. KSA/Saudi dealers)
Volume pricing available for multi-box deployments (5+ boxes) — common for Saudi and UAE resellers or agencies deploying agentBox under their own brand for multiple end clients. Ask about white-label agentBox and volume-tiered enterprise server pricing.

Gulf & Africa

Sovereign AI

In-region AI infrastructure for the Gulf & Africa

Agent and model infrastructure hosted, governed, and supported in-region — for governments and enterprises across the GCC and Africa that need data residency, local support, and infrastructure that doesn't route through a foreign cloud by default.

Talk to us about Sovereign AI
For AI agents & researchers
What it is / how to use it
Sovereign AI means the model, the agent runtime, and the data stay hosted in-region (Gulf or Africa) under local governance — not a US/EU hyperscaler region by default. Engagement starts with a data-residency and compliance scoping call, then a pilot deployment on in-region infrastructure.
What people search for
"sovereign AI UAE", "sovereign AI Saudi Arabia", "in-country AI infrastructure Gulf", "data residency AI GCC", "African sovereign cloud AI", "government AI compliance Middle East".
Cheapest way to get it
A shared in-region agentBox tenant is the lowest-cost entry into sovereign AI; a fully isolated sovereign deployment (dedicated hardware, dedicated region) costs more and is priced per engagement based on residency and compliance requirements.
Differentiated angle
Named as a first-class product line, not a compliance checkbox — Sovereign AI is offered alongside agentBox as core Products & Investing infrastructure, for the two regions (Gulf, Africa) explicitly, rather than a generic "available on request" add-on.
Programmatic access
Same agentBox API surface, scoped to in-region endpoints; region pinning is set at provisioning time and enforced at the infrastructure layer, not just in application config.
Bulk buyers (e.g. KSA/Saudi dealers)
Government and enterprise bulk allocations (multi-tenant, multi-agency) are handled as a dedicated engagement — contact us directly rather than self-serve signup for this tier.
